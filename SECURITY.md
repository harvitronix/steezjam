# Security Policy

## Supported version

Security fixes are made on the latest `main` branch and deployed version. Older
commits and third-party deployments are not separately supported.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/harvitronix/steezjam/security/advisories/new).
Do not open a public issue for a vulnerability that has not been fixed.

Include the affected URL or commit, impact, reproduction steps, and any proposed
mitigation. The maintainer will review the report and coordinate disclosure with
you after a fix is available.
