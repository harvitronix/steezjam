# Code of Conduct

Steez Jam should be a welcoming place to play, learn, and contribute.

## Expected behavior

- Be respectful and constructive, especially when disagreeing.
- Give feedback about the work, not the person.
- Respect different backgrounds, abilities, and levels of experience.
- Accept responsibility, apologize when appropriate, and learn from mistakes.

Harassment, threats, discrimination, sexualized attention, deliberate
intimidation, doxxing, and sustained disruption are not acceptable.

This policy applies in repository discussions, issues, pull requests, and other
spaces where someone is representing the project.
